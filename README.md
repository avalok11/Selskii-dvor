# Ферма «Теремок» — клиентский макет MVP

Статичный прототип клиентской части: витрина живых животных, карточка лота,
вход, личный кабинет с историей заказов, оформление и экран оплаты.
Чистый HTML/CSS/JS, без сборки — открывается двойным кликом.

## Что открыть

| Файл | Экран |
|---|---|
| `preview.html` | **Старт отсюда** — все экраны в рамках телефона (390 px) и планшета (820 px) |
| `index.html` | Главная: hero, витрина лотов, «как выращиваем», сезонный прайс на живой вес, как получить животное, FAQ, вход |
| `lot.html` | Карточка конкретного животного: галерея, видео, характеристики, ушная метка, ветстатус, документы |
| `login.html` | Вход: email-код, Telegram, MAX |
| `account.html` | «Мои заказы»: история заказов, статусы, действия, профиль и привязанные аккаунты |
| `checkout.html` | Оформление: данные → способ оплаты → ссылка (3 шага) |
| `payment.html` | Оплата: QR, таймер, ссылка СБП, копирование ссылки |

## Концепция

Продаём **только живых животных**: барашки и козлята под заказ, каждое — с
номером, весом, возрастом, ушной меткой и фиксированной ценой. Мясо, разруб,
фасовка и документы на мясную продукцию в проекте **не участвуют**.

## Что здесь заложено (переносится в приложение)

| Макет | Модель / механизм |
|---|---|
| Карточка лота, фиксированная цена, статусы «Доступен / Забронирован / Продан» | `Lot` |
| Снять с продажи | `Lot.status = expired`, `Product.isActive = false` |
| Сезонные цены на живой вес (весна / лето / осень-зима) | `Season` + `Price` → цена лота считается при выставлении |
| Бронь 24 часа | `Lot.holdUntil` + таймер |
| Депозит 30% и остаток при передаче животного | `Order.depositAmount`, `Order.balanceAmount` |
| Шаги оплаты | `POST /api/orders` → `Init` Т‑Банка → вебхук `NotificationURL` |
| «Ссылка отправлена» | Бот Telegram + уведомление в MAX |
| Вход по email | код из письма, 6 цифр, TTL 10 минут |
| Вход через Telegram | валидация `initData` (HMAC-SHA256, токен бота) |
| Вход через MAX | валидация `window.WebApp.initData` (MAX Bridge, `hash`) |
| Привязка нескольких способов к одному аккаунту | `User` + `UserIdentity` (email / telegram / max) |
| История заказов | `GET /me/orders` — список с фильтром по статусу |
| Ушная метка и учёт в «Хорриоте» | `Lot.usnm`, `Lot.vetStatus` — вносится вручную |
| Документы на животное | `VetDoc` (файл в S3) + отправка в мессенджер |

## Как править

* **Тексты и цены** — прямо в HTML, всё в одном файле на экран.
* **Сезонные цены** — массив `SEASONS` в `assets/app.js`.
* **Цвета и отступы** — переменные в начале `assets/styles.css` (`--green`, `--terra`, `--cream`).
* **Фото** — заменить файлы в `assets/`, имена менять не нужно.

## Что проверить перед показом

1. На телефоне (390 px): меню-бургер, порядок блоков, размеры кнопок.
2. На планшете (820 px) — две колонки в карточке лота и в оформлении.
3. Вход: «Получить код» → появляется поле кода → «Войти».
4. Шаги оформления: «Дальше — к оплате» → «Сформировать ссылку».
5. Переключение сезонов в прайсе.
6. «Мои заказы»: три статуса — ждёт оплату, готово к передаче, завершён.

Данные вымышленные: цены, веса, контакты и документы — заглушки.
